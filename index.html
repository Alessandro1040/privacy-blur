Sfoca persone e volti. Estrai testo e formule con IA dedicata. Compila il PDF con StellarLatex. Tutto nel browser.

⚠️ Stai aprendo il file con doppio clic (protocollo file://).
L'OCR avanzato (PaddleOCR) richiede un server HTTP per scaricare i modelli. Per usarlo, avvia un mini-server nella cartella del file:

python3 -m http.server 8000

Poi apri http://localhost:8000/index.html.

Nel frattempo l'app usa Tesseract.js (OCR classico, funziona anche da file://). La sfocatura e la compilazione PDF funzionano normalmente.
